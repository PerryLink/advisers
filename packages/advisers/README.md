# advisers

The cordis-only distribution of **Advisers** — a staff of AI advisers with one
continuous conversation, a user ledger, a commitment ledger, and reviewable
routines.

This package is bootstrapping. The runtime core lives in the repository:

https://github.com/PerryLink/advisers

## Status

`0.0.1` reserves the name. The first functional release will expose:

- `createAdvisers()` — headless runtime;
- `advisers` CLI — the first adapter;
- Link SPI — email / Satori / dsh-im / gateway providers.
