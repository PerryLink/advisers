## 6. AI 生成内容的风险

6.1 **可能出错**：AI 生成内容可能错误、不完整、过时、自相矛盾或带有偏见，可能“一本正经地编造”事实、引用、数据、法条与来源。

6.2 **不构成专业意见**：本软件不提供法律、医疗、财务、税务、心理、安全等专业意见。AI 生成内容不得作为上述事项决策的唯一依据；涉及重大权益、人身安全、合规义务的事项须由具备资质的专业人士复核。

6.3 **上游限制**：模型服务商可能对输入/输出进行安全审核并拒答，可能返回不完整结果，可能产生计费；上游拒答不代表内容必然违法。

6.4 **人工复核**：重要结论、对外交付物与公开发布内容必须经人工复核与必要授权后方可使用。

## 9. 数据、个人信息与客户数据

9.1 **本地数据面**：本软件默认在你的设备本地运行：不内置账号系统、云服务、遥测、自动更新检查或运营者控制的服务器；默认不向运营者发送数据。你的账本、对话、附件、研究记录、日历、审计链与配置默认保存在 `ADVISERS_HOME`（默认 `~/.advisers`）下的 SQLite 数据库及关联文件中；目录按 0700、主要文件按 0600 权限创建。**默认不加密**（明文 SQLite）；你可使用 `advisers vault`、`advisers export --encrypted`、`advisers sync` 做可选加密，口令由你保管，遗失不可恢复。迁移/同步/导入可能留下整库副本（`state.db.before-*`、`import-backup-*.db`）与 `undo` 文件副本，这些副本不会自动清理，含全部个人信息。详见 [docs/PRIVACY.md](https://github.com/PerryLink/advisers/blob/main/docs/PRIVACY.md)。

9.2 **运营者的角色**：运营者是本软件的发布者，不接收、不存储、不访问你在本机处理的数据，不构成你数据的个人信息处理者；本软件不向你收集个人信息。你通过仓库 issue、邮件等渠道主动提供给维护者的信息，由相应平台与维护者仅为沟通、缺陷修复与安全响应目的处理；请勿提交客户数据或其他人的个人信息。

9.3 **会出网的情形**：仅在下列情形数据会离开你的设备；未列明的功能不出网：

（a）**模型调用**：设置 `ADVISERS_API_KEY` 后，`chat`、`capture`、`review`、`brief --deep`、`learn review` 及其他模型类命令会把相关输入（可能包含你附加或读取的文件内容、账本摘要、对话）发送给你配置的模型服务商；**默认服务商为 DeepSeek（默认端点 <https://api.deepseek.com>，可用 `ADVISERS_BASE_URL` / `ADVISERS_PROVIDER` / `ADVISERS_MODEL` 修改）**。未设置 API Key 时模型类命令不出网。

（b）**网页研究**：`advisers research --web|--url` 需显式 flag，会把查询词/URL 发送给模型服务商的服务器端联网工具并取回结果；受保护事项（secrecy>0）被 fail-closed 拒绝。

（c）**邮件导入**：`advisers capture --from-imap` 会连接你配置的 IMAP 服务器（只读、TLS），凭据仅从环境变量读取、不写入磁盘；邮件内容会导入本机账本或候选。

（d）**通知（webhook 与自定义命令）**：`ADVISERS_NOTIFY_WEBHOOK` 启用后，向该 URL POST 提醒的计数、级别与日期（不含标题、客户名、动作、证据）；`ADVISERS_NOTIFY_CMD` 执行你指定的本地命令。

（e）**同步**：`advisers sync push|pull` 只读写你指定目录中的加密快照；该目录若由 OneDrive、Dropbox、Syncthing 等同步，快照会随之复制到相应云服务；文件名含设备名与时间。

（f）**宿主与客户端**：`dsh-advisers` DSH 宿主、`advisers mcp --stdio` 的 MCP 客户端、桌宠消费端等第三方程序可能把其取得的数据发送给各自的模型或云服务；其处理受其自身条款约束。

（g）你自行配置的 OCR、时间戳、通知命令等外部命令。

（h）**桥接（bridge / Hermes 文件网关）**：运行 `advisers bridge --dir <目录>`（需另行安装并配置 Hermes bridge-adapter；该命令为受门控命令，需先接受当前版本的本 TOS）后，本软件会持续轮询该目录并与你的 Hermes 进程交换 JSON 文件；本软件本身不直接建立网络连接，对外发送由 Hermes 及其接入的平台完成。**收到（inbox）**：来自 Hermes 的消息 JSON（消息文本、发送者标识、会话/线程 ID、附件元数据、回复关系）会导入本机账本，并可能作为模型调用上下文发送给你配置的模型服务商（默认 DeepSeek，见 (a) 条）；**发出（outbox）**：回复文本、附件引用与幂等键会以**明文 JSON** 写入该目录，交由 Hermes 及其接入的消息平台（如 Telegram、飞书、企业微信、Slack、Discord、Email 等，取决于你的 Hermes 配置）处理；目录按 0700、文件按 0600 创建。该目录若位于 OneDrive、Dropbox、Syncthing 等同步盘或共享盘，其中明文 JSON 可能被复制到你未预期的位置，请将 bridge 目录指向本机受控路径。受保护事项（secrecy>0）的模型调用按 fail-closed 拒绝；bridge 进程运行期间按轮询间隔持续工作，停止该命令即停止本软件侧的该通道。

除上述外，本软件**不含遥测、无自动更新检查、不内置运营者服务器地址**。

9.4 **第三方服务商**：上述服务商（含 bridge 场景下你的 Hermes 进程及其接入的消息平台）是独立的个人信息处理者或受托处理者（取决于其条款）；运营者不控制其处理、不代其作出留存/训练/删除承诺。你应在启用前阅读其服务条款与隐私政策，并自行决定是否接受其数据使用、留存与跨境安排。
