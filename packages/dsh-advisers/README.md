# dsh-advisers

The DeepSeek Harness distribution of **Advisers**. It mounts the same
cordis-native secretary core as `advisers`, but uses DSH's session, agent, LLM,
tool, and approval services, and can bind `dsh-im` links.

This package is bootstrapping. The shared core lives in:

https://github.com/PerryLink/advisers

## Status

`0.0.1` reserves the name. The first functional release will ship a DSH bundle
(`cordis.patch.yml`) that mounts the `advisers` core.
