# Continuity — 200 facts / 12 probes — 2026-11-14

Model: `deepseek-flash`, real CLI, throw-away `ADVISERS_HOME`. Script:
`eval/run-continuity.mjs` (`FACTS=200`). Each fact stored with one
`advisers chat "<fact>"` call, then 12 generated probes.

## Result

**12/12 probes passed, 0 failures**, elapsed 2,405,714 ms (~40.1 min), exit 0.

Coverage: 10 categories × 20 rounds (person/client/budget/project date/
preference/commitment/owner/company/email/deadline), deterministic unique facts.
Probes include facts from later rounds; this is the longest continuity soak run
so far and exercises recall far beyond the fresh context window.

## Caveats

- "200 facts" = 200 stored facts + 12 probes, not a 200-turn user conversation
  transcript. It does exercise long-context recall and compaction boundaries, but
  it is not a substitute for a multi-day real conversation soak.
- Synthetic unambiguous facts; one run only.
- The 50/100-fact runs are in `continuity-50-2026-11-14.md` /
  `continuity-100-2026-11-14.md`.
