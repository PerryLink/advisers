# Continuity — 100 facts / 10 probes — 2026-11-14

Model: `deepseek-flash`, real CLI, throw-away `ADVISERS_HOME`. Script:
`eval/run-continuity.mjs` (`FACTS=100`). Each fact stored with one
`advisers chat "<fact>"` call, then 10 generated probes.

## Result

**10/10 probes passed, 0 failures**, elapsed 1,109,142 ms (~18.5 min), exit 0.

Coverage: 10 categories × 10 rounds (person/client/budget/project date/
preference/commitment/owner/company/email/deadline), deterministic unique facts.
Probes include facts from later rounds, so this exercises recall well beyond the
fresh context window.

## Caveats

- 100 facts is not 200 turns; the 200-turn compaction behaviour is covered by
  deterministic unit tests but **not** by a real-model soak in this run.
- Synthetic unambiguous facts; one run only.
- The 50-fact run (`continuity-50-2026-11-14.md`) is the one used for the
  before/after harness discussion; this 100-fact run uses the final harness.
