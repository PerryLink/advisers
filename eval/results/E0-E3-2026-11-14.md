  `due-today-18`, `overdue-daily`, `snooze-wake` (+`upcoming`).
- CLI test: `remind --json` bucket, `remind --ics` writes VEVENT+VALARM (stable UID),
  `remind install/status/uninstall` scripts under `~/.advisers/scheduler`.

- Limits: no native toast on this host (no `notify-send`/BurntToast); the verified
  path is calendar import + scheduler log. 24h wall-clock delivery is NOT run here.

## E3 — evidence / delivery

- Module tests: `evidence.test.js` 15/15 (source resolution, missing reasons,
  deterministic manifest, SHA256SUMS, tamper detection, quote cap/no paths).
- CLI test: `evidence show <cm_...> --json` returns the real turn; `deliveries
  --pack --out` writes `manifest.json`, `README.txt`, `SHA256SUMS`,
  `receipt.docx`; recomputed SHA256 matches every entry.
- `deliver --type ledger --out ledger.xlsx` writes an XLSX with ID/对象/事项/截止/
  状态/证据数/来源 columns.
- Tamper caveat: SHA256SUMS is tamper-evidence, not a signature/third-party
  timestamp; this is stated in README.txt and the task plan.

## Known limits

- No PDF generation yet (PDF read exists); no OFD/OCR; no at-rest encryption.
- No end-to-end IMAP/OAuth; `.eml/.mbox` only.
- No native OS notification adapter verified; `.ics` + scheduler scripts only.
- All real-model runs are single-run smoke, not a new benchmark.
