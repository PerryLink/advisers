# 中文承诺标注指南（独立人工金标）

## 任务
阅读每条工作内容，标出所有**明确承诺/义务**。只抽承诺，不抽请求、客套、计划、愿望。

## 字段
- `action`：12 字以内动词短语，去掉“把/给+人名”；例：`发报价`，不是“把报价发给王工”。
- `debtor`：`user`（我承诺）/`third`（对方承诺）/`unknown`。
- `creditor`：对方名字；未知留空。
- `due`：`YYYY-MM-DD`（Asia/Shanghai）。相对日期以消息日期为基准；无法确定留空。
- `quote`：必须逐字来自原文，不改标点/不补字。
- `modal`：`firm`（我会/一定/周五前）/`tentative`（尽量/争取/应该）/`conditional`（如果/前提）。
- `confidence`：0–1；`notes`：歧义原因（可选）。

## 规则
1. 同一天说“周五前”按自然阅读；有歧义写 notes，不要猜一个隐藏规则。
2. “当天/这两天/回头/尽快”等模糊表达：无法确定就留空，不硬填日期。
3. 不要把“祝好/收到/谢谢”当承诺；不要把“如果…再说”当 firm。
4. 一条内容可有多条承诺；没有就留空该行。
5. 独立完成，不参考另一评审的表；不打开 `adjudicator-only/`。

## 交付
填完 `labels-reviewer-a.tsv` 或 `labels-reviewer-b.tsv`，保持 id 原样；
交给裁决者合并，不要自行修改别人的表。
