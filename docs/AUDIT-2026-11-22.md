# 审计摘要：Advisers 作为「秘书」的能力边界（2026-11-22）

> 基线：产品仓 `main` `af53896`（0.4.1 已发布，tag `v0.4.1` = `1a05f7c`）。
> 方法：8 份独立核对报告，逐条对照代码、文档与实测；产品仓只读，测试一律使用临时
> `ADVISERS_HOME`（`mktemp` + `ADVISERS_ACCEPT_TOS=1`），未读写真实 `~/.advisers`。
> 本页是 8 份报告的综合摘要与对外能力边界，不是法律意见、SLA 或模型质量证明；
> 完整核对材料为内部研究，不随本仓库发布。

## 1. 结论概览

- 六点批评（输入 / 记忆 / 执行 / 主动性 / 交互 / 可携带与商业）**方向大致成立**，
  但原批评含 **5 处硬事实错误**、约 12 处需要限定词；同时漏掉了 10 类对「秘书体验」
  重要的事实与能力（信任链、同步/备份、数据权利、Office 广度等）。本页第 3 节逐条纠偏。
- 定位冲突成立：README 曾自称 "personal secretary runtime"，而
  [POSITIONING.md](POSITIONING.md) 明确把常驻录音 / 移动 App / 自动代发列为非目标。
  2026-11-22 已对齐叙事（见 [README](../README.md)、[README-zh](../README-zh.md)、
  [POSITIONING.md](POSITIONING.md)）。
- 真实缺口不是「有没有 daemon」，而是：① 质量证据（独立人工金标 / 真实匿名语料 /
  发布门禁）；② 数据安全（自动备份、sync 冲突合并、迁移与丢机恢复演练）；③ 输入自动化
  （OAuth 现实、收件箱 watch、剪贴板 / 手机来源）；④ 最后一公里（发送 / 日历写回 / 发票，
  与定位冲突，需先做产品决策）；⑤ 可达性（云 push / 重试 / 伴侣端）。
- 可信度边界：审计 hash-chain + 离线回执只能证明「包内自洽 + 本地审计」，不含第三方
  可信时间戳；确定性契约评测（`eval:det`）不等于模型质量。

## 4. 能做 / 不能做（0.4.1 能力边界）

### 4.1 能做（有实现与文档/测试证据）

- **本地承诺账**：who owes whom / due / evidence / 人工 accept / 回执；中文承诺语义与相对日期解析；matter / client / project 与派生时间线。
- **确定性节奏**：`morning` 晨报（`dataSha256`、归档）、`agenda`、urgency v1（`terms`/`whyNow`）、提醒 / `.ics` / VALARM、安静时段、按本地日去重、`--force-notify`。
- **Office 交付**：6 构建器 + 7 通用模板 + 2 确定性模板、`office-read`/`office-edit`/`verify`、回执包与离线 `evidence verify`、OFD 读取与显式本地 OCR（`ADVISERS_OCR_CMD`）。
- **知识库**：本地摄取（文本 / OOXML / PDF / OFD / `.eml`，图片待 OCR）、FTS5 trigram 检索、确定性编译页、`fact show/history/as-of` 时间旅行、`kb link/unlink`。
- **邮件**：只读 TLS IMAP `mail sync`、`.eml`/`.mbox` 导入、本地规则抽取（pending 候选，人工 accept）、正文默认 30 天保留；凭据 0600 且不进 DB / 导出 / 备份 / 同步。
- **客户 / 钱**：receivables/payments 本地记账（整数分、多币种、部分/超额/void）、客户状态包 v2（不含金额）；金额不进回执、客户包、MCP/DSH 或 Pet Brief。
- **信任 / 数据权利**：审计 hash-chain + 可选尾锚、回执离线校验、`privacy --matrix/--prove`、`purge`、`redact-names`、consent revoke、手动 E2EE sync、`backup/restore`、opt-in `vault seal`。
- **宿主集成**：MCP 8 工具 / 5 只读 resources（读 + pending-only capture）、DSH 6 工具（账本只读 + `advisers_office` 在 workspace 写）。
- **Windows**：`windows-smoke` 与 `windows-full` 两个 blocking CI（Node 22.16/24，Server 2025 镜像）、npm 正式渠道、便携 ZIP 构建/校验、真机 0.4-line CLI smoke 29/29。

### 4.2 不能做 / 未验证（不要宣传成能做）

- **常驻 / 在场**：没有常驻录音、会议转写、常驻 daemon、收件箱监听或自动采集——这是产品非目标或未实现，不是隐藏开关。
- **伴侣端与推送**：没有移动 App、伴侣端、云推送服务、推送重试 / outbox；错过调度不补跑。
- **代发 / 改期**：没有 SMTP 发送、IM 主动群发、自动代发或自动改期；飞书 link 库未接线，微信无实现，IM 必须另装 Hermes 网关。
- **日历**：没有 CalDAV / OAuth / 写回 / 邀请 / 约时间；只有 `.ics` 单向导入/导出，固定 Asia/Shanghai，RRULE 仅展开 DAILY/WEEKLY（MONTHLY/YEARLY 回退 DTSTART）。
- **邮件**：无 OAuth、无附件下载、无发送/写回、无 IDLE；Gmail Workspace/M365 密码 IMAP 上游被禁（前序研究转引，本轮未联网复核），内置入口对这类账号实际不可用。现有 `mail account test` 只做只读 IMAP 探测（TLS/LOGIN/CAPABILITY/EXAMINE），`mail sync --watch` 是前台轮询、不是常驻服务。
- **自主执行**：只有前台、人工触发、需要模型 key 的交互式 agent（最多 8 步工具调用）；没有后台自主多步。
- **记忆自动化**：没有自动事实抽取、语义检索 / RAG、`kb ask`、模型生成 wiki、自动客户识别 / CRM；KB / mail / facts 之间不自动连通。
- **财务**：没有发票、收款通道、对账、FX 或资金移动；receivables 只是本地记账。
- **质量证据**：仍没有独立人工金标、真实匿名语料或模型质量的发布门禁；本地邮件抽取已有 30 个合成 fixture 的零模型金标（`pnpm eval:mail-local`，已进 Linux CI），但标签由实现者手写、非独立人工复核，不能当通用准确率。模型抽取/`capture` 的质量仍只有手动 eval、不进 CI。
- **真实账号验收**：没有真实 IM / 邮箱账号 dogfood；Hermes 网关未在本轮审计中安装/运行验证。
- **真实 Windows 客户端**：IME、Office/WPS、OneDrive、Defender 未在 Win11 真机验证；CI 是 Server 2025，不等于 Win11 客户端；真机记录首跑 36 项已知失败/跳过。
- **默认安全边界**：整库默认明文，`vault` 是非透明 opt-in；凭据无系统钥匙串 / OAuth；凭据刻意不进备份 / 同步；审计与回执无第三方可信时间戳。
- **企业能力**：无团队 / 多用户 / SSO / 权限系统；无运行时插件市场 / 工作流 DSL；无 MSI / Store / 签名 EXE / 自动更新。
- **商业使用**：PolyForm NC 下，为付费客户业务使用 / 以输出交付须先取得书面商业许可；无公开价格 / SLA。

## 4.3 本轮已补（已随 0.4.2 于 2026-11-22 发布）

以下是为了把审计里"能做的"落地而新增的主线改动；均为本地/确定性能力，未改变 schema、TOS 版本或已发布 0.4.1 资产。这些改动已作为 **0.4.2（2026-11-22 发布）** 发布：

- **手工事实录入**：`fact add <subject> <predicate> <object> --quote "..."`，写 `authority=user`、`status=confirmed` 的 fact，支持 `--matter`/`--valid-from`/`--supersedes`/`--doc`/`--relation`；quote 必填、重复幂等、事务内一条 `fact.add` 审计，失败全回滚。
- **邮件只读探测**：`mail account test <account>`（TLS/STARTTLS/LOGIN/CAPABILITY/EXAMINE，30s 上限，不抓正文、不写邮件表）；本地 `.eml` 账号无服务器时无网络 fail-closed。
- **前台收件轮询**：`mail sync --watch [--interval 300s] [--max-runs n]`，每轮开/关账本（空闲不持写锁）、失败指数退避、Ctrl+C 在当前轮结束后停止；仍是显式前台进程，不是 daemon。
- **同步安全预览**：`sync pull --dry-run` 完成选快照/解密/SHA-256/本地状态判断，但不换库、不写备份/临时文件/审计，返回 `wouldChange/wouldStatus/wouldBackup`。
- **备份年龄提示**：`doctor --check-db` 的 `db-backup` 行附带最新托管备份的年龄（>7 天提示 `advisers backup`），只提示不失败。
- **子命令帮助一致性**：`kb add --help`、`mail account add --help`、`client show --help`、`project show --help`、`doctor --help`、`mail sync --help` 等现在都打印自身 usage 且可在 TOS 接受前运行。
- **本地邮件抽取金标**：新增 30 个合成 `.eml` + labels + `pnpm eval:mail-local`，指标 precision/recall/F1/due/author 有阈值，零模型/零网络，已接入 Linux CI；这是回归门，不是通用准确率声明。
- **文档纠偏**：README/README-zh/POSITIONING 明确 non-goals；EVAL 修正 windows-full 为 blocking；WINDOWS 区分 Server 2025 CI 与 Win11 真机；KB/CLIENTS/REMINDERS 补审计核实边界。

**仍未做/不能做**：OAuth/CalDAV/发送/日历写回/发票支付通道/常驻 daemon/移动 App/云推送/语义 KB/自动事实抽取/独立人工金标/真实账号 dogfood/Windows 真机 IME-Office 矩阵/团队与商业许可条款；这些受产品 non-goals、外部账号/法务/人力或模型依赖限制。
